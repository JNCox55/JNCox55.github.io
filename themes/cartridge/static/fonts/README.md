# Fonts

Both fonts are free under the SIL Open Font License 1.1 (license texts are in this folder).
They're the Latin subset (`latin-400-normal`) from [Fontsource](https://fontsource.org),
renamed to the filenames `base.css` expects.

| File | Font | Source |
| --- | --- | --- |
| `PressStart2P-Regular.woff2` | Press Start 2P (headings, UI) | https://cdn.jsdelivr.net/npm/@fontsource/press-start-2p/files/press-start-2p-latin-400-normal.woff2 |
| `VT323-Regular.woff2` | VT323 (CRT screen) | https://cdn.jsdelivr.net/npm/@fontsource/vt323/files/vt323-latin-400-normal.woff2 |

To update them, download from the URLs above and save over these files with the same names.

These subsets don't contain ▶ ◀ ▼ ↩ ★ 🔍, so the theme draws them as pixel-art SVGs
instead. See "Icons" in the project README.
